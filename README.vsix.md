# CodePractice

CodePractice は、VS Code 上でコーディング練習を進めるための拡張機能です。

主な機能:
- Java / TypeScript / SQL の練習問題
- AI モードとオフラインモード
- 実行、判定、ヒント、Quick Solve、解説表示
- 進捗管理と復習機能
